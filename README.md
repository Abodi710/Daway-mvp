# دواي (Daway)

منصّة سودانية تربط المرضى بالصيدليات المعتمدة والموردين: بحث عن الأدوية وأسعارها وتوفّرها، طلب ودفع عبر بنكك، وإدارة مخزون الصيدلية وطاقمها ونقطة البيع.

## التشغيل

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env    # ثم عبّئ JWT_SECRET و ADMIN_EMAIL و ADMIN_PASSWORD
```

**أثناء التطوير** (نافذتان):

```bash
npm run server   # الخادم على المنفذ 5000
npm run dev      # الواجهة على http://localhost:3000
```

**للإنتاج** (منفذ واحد يخدم الواجهة والـ API):

```bash
npm run build
npm start
```

## الأدوار

| الدور | ما يستطيعه |
|---|---|
| مدير النظام | مراجعة طلبات الصيدليات، إدارة المستخدمين وإيقافهم، كل الأدوية والمبيعات |
| مالك صيدلية | المخزون، الموظفون، طلبات العملاء ومراجعة إيصالات الدفع، المبيعات والتنبيهات |
| موظف صيدلية | نقطة البيع، إضافة أدوية، طلبات العملاء |
| مورّد | كتالوج الجملة، تنفيذ أوامر التوريد |
| عميل | البحث والطلب، رفع إيصال بنكك، متابعة الطلبات وإلغاؤها |

التسجيل العام يُنشئ حساب عميل فقط. الصيدليات تقدّم طلب انضمام يراجعه المدير.

## ملاحظات أمنية

- لا ترفع أبداً ملف `.env` أو `daway.db` أو مجلد `uploads/` (إيصالات الدفع) إلى المستودع.
- `SEED_DEMO_DATA=true` ينشئ حسابات تجريبية بكلمة مرور معروفة — للتطوير فقط.
- تفاصيل البنية والقواعد التي يجب الحفاظ عليها في [CLAUDE.md](CLAUDE.md).
